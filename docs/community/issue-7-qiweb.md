# 易用性建议：会话导入导出、多组模型配置、取消任务的边界

来源：[issue #7](https://github.com/WhiteNightShadow/firefox-reverse/issues/7)，[@QIWEB](https://github.com/QIWEB)，2026-08-11。以下为原文摘录，按原优先级从高到低：

> **1、我办公电脑上有很多会话，我想回家电脑上也能有解决思路或者过程，所以希望加一个历史会话导出导入的功能！**
>
> 2、我平时有3套大模型服务商，所以地址，key和模型都不一样。 我每次修改一次就覆盖了上一组配置。比较麻烦。所以希望这个可以多组 可选择默认配置模型
>
> 3、就是我设置了一个路径后，对话过程中我中断或者取消任务，若是不换新对话，再问其他话题，他会记录以前的没完成任务继续干。这个可以提醒用户是另外一个话题，或者记住我手动取消的任务后面不用再执行。
